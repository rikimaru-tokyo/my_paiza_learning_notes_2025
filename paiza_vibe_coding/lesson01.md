# 02:作成するアプリの概要と手順

## 作成するアプリの概要 : 日本の経済指標のダッシュボード

- 必ず実装する機能を洗い出しておこう!
- 初心者の人は簡単なアプリから始めよう!

## 手順

一度の指示でアプリを完成させようとするのはあまり良い手ではありません

→　少しずつAIに指示を出して確認しながら完成に近づける

- 前提:Pythonを使う
  1. タイトルだけが表示されたダッシュボードを作成
  2. 経済指標のデータを取得(消費者物価指数)
  3. 折れ線グラフを作ってダッシュボードに表示
  4. 景気動向指数も同様にデータを取得しグラフで表示
  5. データを元にAIが経済状況を分析する機能をつける
